# CHV — Agent Guidance

`AGENTS.md` is the canonical, single source of truth for coding-agent
orientation in this repository: repository direction, build commands,
release engineering, proto generation, implementation rules, and
context/token-efficiency discipline.

Read [`AGENTS.md`](AGENTS.md) first. This file is kept as a pointer only so
agent harnesses that load `CLAUDE.md` by name are routed there — there is
deliberately no duplicated policy here, so the two files cannot drift.

For the human-side workflow (dev setup, code style, PR process, and the
high-risk-change review rule), see [`CONTRIBUTING.md`](CONTRIBUTING.md).

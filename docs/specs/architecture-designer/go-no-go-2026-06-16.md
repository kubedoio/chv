### G4 — Reviewer-MAJOR closure rate = 100%

Across Phases 0–7, every reviewer-MAJOR or "important" finding was closed in the
same PR that surfaced it. Notable patterns the reviewer panel caught and the
authoring agents fixed:

- Phase 5 idempotency key format ambiguity → rejected `::` and `/` in resource names
- Phase 5 production-environment guard bypass (operator could write `production` label) → admin escalation enforced at handler entry
- Phase 6 unbounded `seen` Set on reconnect → bounded LRU + reconnect-on-stale guard
- Phase 6 callback inside JSON-parse `catch` swallowed exceptions → split try-blocks
- Phase 7 stale-plan TTL boundary off-by-one untested → 3 boundary tests (T0+15m−1ms / exact / +1ms)

**Verdict:** ✅ GO — no reviewer-MAJOR carryover.

### G5 — Permission posture audited

The Phase 7 permission matrix asserts every architecture endpoint × every role at
the routing layer. Production-environment escalation (operator → 403 on prod-env
apply, admin succeeds) is asserted in `apply_production_environment_as_operator_returns_403_production_requires_admin`
and `apply_production_environment_as_admin_succeeds`. The matrix's
`include_str!`-based exhaustiveness meta-test prevents future routes from slipping
in without coverage.

**Verdict:** ✅ GO — no enumerated permission combination is unverified.

## Risks at ship and mitigations

| Risk | Likelihood | Impact | Mitigation in place |
|---|---|---|---|
| Drift CheckFailed flaps under fleet pressure | Medium | Low (user-facing badge only) | 5-min cache + `force_refresh`; explicit `Unknown` metric label; Prometheus template in OPERATIONS |
| Plan TTL clock skew between BFF and orchestrator | Low | Medium | `state.clock` injection; troubleshooting entry in OPERATIONS; boundary tests pin `>` semantics |

| New table growth (`inventory_snapshots`, `drift_reports`) | Medium | Low until very high | Retention documented; pruner spec ([`snapshot-pruner-followup.md`](../../plans/2026-06-16-snapshot-pruner-followup.md)) |

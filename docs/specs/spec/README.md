# Specifications (Executive Summaries)

This directory contains short executive-summary specs. **They are not the canonical
source for any decision.** Each WebUI summary points at its canonical ADR or component
spec. For binding requirements, read the canonical doc the summary links to.

Non-WebUI specs in this directory (e.g. live-migration-spec.md, vxlan-overlay-spec.md)
are working specs for cross-cutting features and ARE canonical for their topic.

# Specifications (Executive Summaries)

This directory contains short executive-summary specs for the WebUI. **They are
not the canonical source for any decision.** Each WebUI summary points at its
canonical ADR or component spec. For binding requirements, read the canonical
doc the summary links to.

All specs in this directory are WebUI summaries. Cross-cutting working specs are
canonical for their topics and live in sibling directories:

| Directory | Contents |
|---|---|
| [`../component/`](../component/) | Component and cross-cutting specs (for example `live-migration-spec.md`, `vxlan-overlay-spec.md`, `disk-migration-protocol-spec.md`) |
| [`../ops/`](../ops/) | Operator references and matrices |
| [`../contracts/`](../contracts/) | External compatibility contracts |
| [`../adr/`](../adr/) | Decision records |

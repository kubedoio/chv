## 2023-10-27 - Icon-only button accessibility in data tables\n**Learning:** Icon-only buttons within table rows (like Edit/Delete actions) often lack proper accessibility context and use internal/developer-centric text for `title` tooltips (e.g., `MODIFY_ENTITY`), making them unusable for screen readers and confusing for sighted users.\n**Action:** Always add descriptive `aria-label`s with row-specific context (e.g., `aria-label="Edit user {row.username}"`) and update `title` attributes to be user-friendly (e.g., `title="Edit user"`) for icon-only action buttons in data tables.
